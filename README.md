# Meltype Android (QWERTY + Glide Typing)

日本語と英語をモード切替なしで自動判別してライブ変換する **Meltype** の考え方をもとに、Android 向けに **QWERTY 配列** と **グライド入力（スワイプ入力）** を実装したオフライン IME です。

## 主な特徴

- **日英シームレス自動判別・ライブ変換**:
  - `kyouhagoogledekensaku` → `今日はgoogleで検索`
  - `ashitanomeetingwotsuika` → `明日のmeetingを追加`
  - `ra-men` → `らーめん` → `ラーメン`（日本語文脈中のハイフン長音連結に対応）
  - `I want to go to the park` → 英語文としてそのまま保持
  - `/command`, `@mention`, `$variable`, `RTX4090` 等のコマンド・型番・URLを自動保持
- **高速・高精度 日英デュアル・グライド入力（非同期プレビュー＆人間の指軌道対応）**:
  - SHARK2 型重心/スケール正規化 Shape Channel・ステップ方向ベクター Direction Channel・生体力学的な角丸め/折り返しショートカット補正モデル・実弧長比 waypoints 照合を組み合わせ、縮小・平行移動・曖昧なカーブを描いたスワイプでも高精度に復元します。
  - Stage-1 バケット探索への動的コスト上限足切り・8 点粗フィルタ・事前計算重心キャッシュとワーカースレッドでの非同期プレビュー（指移動 115ms スロットリング）により、UI スレッドを止めずに滑らかに追従・確定します。
  - 連続小文字ローマ字の語幹（`makenai` / `homete` / `tameninaru` 等）を無関係な英単語へ誤分割しない助詞境界ガードを搭載しています。
  - ヘボン式 (`watashi`, `ashita`, `shashin`)・訓令式 (`watasi`, `asita`, `syasin`)・長音省略 (`arigato -> arigatou`, `tokyo -> toukyou`)・単一 `n` (`konichiwa -> konnichiwa`)・助詞/発音ゆらぎ (`watashiwa -> watashiha`) に加え、`kakuninshimasu` / `arigatougozaimasu` 等の複合接尾辞 2 分割デコードに対応しています。
  - 5 段階の語彙優先度設計により、日常日本語語彙が 39k 英単語や稀少見出し語に奪われる現象を抑えています。
- **ローマ字ミスタイプ耐性・空間隣接補正 ＆ 撥音・カタカナ誤綴り補正**:
  - タップ座標ベースの QWERTY 物理隣接キー重み付け（`a↔q`・`k↔j` 等）と DP かな格子スコアにより、`onegaishimsu` → `お願いします`・`arigatpu` → `ありがとう`・`qite` → `相手`（`q→a` 隣接補完）等の打ち損じを修復します。
  - 正常な日本語かな列（例: `でんじき` → `電磁気`、`すじ` → `筋`）では誤って別単語へ書き換えず、絵文字や英語固有名詞（小文字入力時の `node` / `siri` 等）が日本語第一候補より優先される問題も防ぎつつ、境界付近タップ時のみ「もしかして」代替候補を併記します。
  - `arigatoi` / `ohayoi` / `watashu` 等「別のかなとして読めてしまう隣接打鍵」や `shimbun` / `sampo`（`mb`/`mp`/`mm` → `ん`）、カタカナ誤綴り辞書（`misspellings.txt`）にも対応しています。
- **左右移動キー（`◀` `▶`）・Gboard 風全量絵文字ピッカー ＆ 便利機能**:
  - 全レイヤー最下段に常設した `◀` `▶` キー（長押し連続リピート対応）で、アイドル時はカーソル移動、変換中は文節移動・境界調整を実行できます。また Backspace 左スワイプで直前の語句・文節を一括削除でき、`↩ 戻す` で即座に復元できます。
  - 上段 `☺` ボタンまたは `日/英` キー上フリックから、**全カテゴリ連続縦スクロール対応の絵文字ピッカー（10 列高密度フレームレス表示・スクロール連動カテゴリタブ＆セクションジャンプ・`Paint.hasGlyph()` 未対応絵文字フィルタ・日本語/ローマ字/英語インライン検索）**・**顔文字（3 列コンパクトグリッド）**・**クリップボード履歴＆定型文＆今日の日付/時刻**・**カーソル/編集パッド（全選択・コピー・切取・貼付・文頭/文末）** パネルを展開でき、画面下半分を広く使ってスムーズに選択できます。
  - 確定直後の **`↩ 戻す` チップ**、囲み括弧 **`「」` / `（）` / `【】` / `""`**（選択範囲ラップ・カーソル内側配置）、`=` 不要のリアルタイム電卓・3桁区切り/漢数字変換も搭載しています。
- **Meltype Studio コンパニオンアプリ**:
  - **スタジオ**（リアルタイム変換サンドボックス・誤字/混在プローブ・実線なぞりデコード実験できるインタラクティブ `GLIDE GEOMETRY LAB`）・**レイアウト・設定**（高さ・数字段・片手配置・句読点・テーマを即時反映するライブ設計プレビュー付き）・**辞書・操作**（ユーザー辞書＆ショートカット一覧）の 3 ワークスペース構成で直感的に調整できます。
- **変換修正のしやすさ**:
  - 入力中の注目文節をテキスト欄内で背景ハイライト表示し、上段の文節ピルタップ（注目文節を `読み▸表記` 形式で表示、再タップで全候補パネル展開）・`◀` `▶`・スペースバー左右スライド（横デッドゾーン付き）で文節を素早く移動できます。
  - 文節バー右側に **`◀` `▶` `短` `長` `確定✓` `日/英`** を固定座標で常時配置（無効状態は半透明表示）し、連文節境界を越えた 1 文字単位の伸縮、前側文節の部分確定（`確定✓`）、日英切替を手が迷わず操作できます。
  - 候補チップをタップすると確定して自動で次の文節へフォーカスが移動し、グライド直後にも候補チップ 4 件から 1 タップで差し替えられます。
  - `▼` ボタンで展開できるオーバーレイパネルから、**字種一発変換**（ひらがな / カタカナ / 半角ｶﾅ / abc / Abc / ABC）・**4列全候補グリッド**・**キーボード高さクイック調整**を即座に操作できます。
- **自由なキーボード高さ・誤爆防止フリック・数字＆記号入力**:
  - 設定画面の連続スライダー＆微調整ボタン（`65%〜155%`、1% 刻み）およびキーボード内の展開パネルから高さを自由に調整できます。
  - QWERTY 最上段に常時表示の数字段 `1〜0`（設定で ON/OFF 可）を備え、グライド用の英字3段座標系と分離されているためグライド精度を損ないません。
  - 長押し判定（0.38 秒・狭半径ガード）と上方向限定フリックにより、文字タップ・グライド・下方向ブレ・スペースバーでの誤爆を防いでいます。文字キーの上フリック記号入力は設定で ON/OFF 可能（既定 OFF）で、最下段の `ー`（上：`〜`）・`、`（上：`！`）・`。`（上：`？`）・`日/英`（上：絵文字）は常に軽い上フリックで入力できます。アイドル時クイック記号バー、`?123` / `=\<` / `テンキー`（電卓・電話番号配列）、記号入力後の自動復帰オプションも搭載しています。
- **組み込み OSS Mozc 変換エンジン**:
  - `libmozc.so` (`arm64-v8a` / `x86_64`) と `mozc.data` によるオフライン連文節かな漢字変換と学習機能に対応しています。
- **その他の機能**:
  - 片手モード（全幅 / 左寄せ / 右寄せ）、ライト / ダーク / システム連動テーマ、ユーザー辞書

## ビルド方法

大容量バイナリ（`libmozc.so`、`mozc.data`）はリポジトリに直接含めておらず、`tools/fetch_mozc_assets.py` が `AoneSenbongi/Meltype-Android` (`android-1.3.0`) から SHA-256 検証付きで展開します。

```powershell
# 初回アセット取得 + 単体テスト + Debug APK ビルド
.\build.ps1
```

または個別に実行できます:

```powershell
python tools/fetch_mozc_assets.py
.\gradlew.bat testDebugUnitTest --no-daemon
.\gradlew.bat assembleDebug --no-daemon
```
